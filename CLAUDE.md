## Project Overview

Jackson modules-base is a multi-module Maven project containing 12 foundational Jackson extension modules that build directly on jackson-databind. Each module is independent (no inter-module dependencies).

**Modules:** afterburner, blackbird, mrbean, guice, guice7, jaxb, jakarta-xmlbind, paranamer, osgi, android-record, no-ctor-deser, spi-subtypes

## Build Commands

```bash
# Full build (all modules)
./mvnw -B -q -ff -ntp verify

# Build a single module
./mvnw -B -q -ff -ntp verify -pl afterburner

# Run tests only (all modules)
./mvnw -B -ff -ntp test

# Run tests for a single module
./mvnw -B -ff -ntp test -pl blackbird

# Run a single test class
./mvnw -B -ff -ntp test -pl afterburner -Dtest=SerializeSimpleTest

# Run a single test method
./mvnw -B -ff -ntp test -pl afterburner -Dtest=SerializeSimpleTest#testIntMethod
```

Java 8 is the minimum; CI tests against 8, 11, 17, 21. JDK 17+ activates a profile adding `--add-opens` flags for afterburner, blackbird, and osgi modules.

## Architecture

Every module follows the same pattern:
- A `*Module` class (e.g., `AfterburnerModule`, `BlackbirdModule`) implements Jackson's `com.fasterxml.jackson.databind.Module` interface, registered on `ObjectMapper`
- Package: `com.fasterxml.jackson.module.<name>` (hyphens dropped or turned into sub-packages: `androidrecord`, `noctordeser`, `spisubtypes`, `jakarta.xmlbind`)
- `PackageVersion.java` is auto-generated by the replacer Maven plugin — do not edit manually
- JDK 9+ module descriptors live in `<module>/src/moditect/module-info.java`
- SPI registration: `src/main/resources/META-INF/services/com.fasterxml.jackson.databind.Module` (all modules except guice, guice7, osgi)

### Key module categories

- **Performance (bytecode generation):** afterburner (ASM-based), blackbird (LambdaMetafactory-based, modern replacement) — both disable themselves automatically in GraalVM native images via `NativeImageUtil.isInNativeImage()` check in `setupModule`
- **DI integration:** guice (javax.inject), guice7 (jakarta.inject) — note: guice's `ObjectMapperModule` implements Guice's `com.google.inject.Module`, not Jackson's `Module` interface
- **Type materialization:** mrbean (generates implementations for interfaces/abstract classes)
- **Annotation support:** jaxb (javax.xml.bind), jakarta-xmlbind (jakarta.xml.bind)
- **Other:** paranamer (parameter name discovery), osgi (OSGi service injection), android-record (Android desugared records), no-ctor-deser (no default constructor), spi-subtypes (SPI-based subtype registration)

### Dependency shading

afterburner, mrbean, and paranamer shade their dependencies into relocated packages:
- ASM → `com.fasterxml.jackson.module.afterburner.asm` / `com.fasterxml.jackson.module.mrbean.asm`
- Paranamer → `com.fasterxml.jackson.module.paranamer.shaded`

## Testing

- **Framework:** JUnit 5 (Jupiter) — migrated from JUnit 4 in Jan 2025
- **Base test classes:** Each module has its own (e.g., `AfterburnerTestBase`, `BlackbirdTestBase`, `ModuleTestBase`, `BaseTest`) providing mapper construction helpers and shared test types
- **Test location:** `<module>/src/test/java/com/fasterxml/jackson/module/<name>/`
- Tests use static imports from `org.junit.jupiter.api.Assertions`
- **Mapper construction in tests:** Use `mapperBuilder()` (returns `JsonMapper.Builder` with module pre-registered) or `newObjectMapper()` factory methods from the test base class; `newVanillaJSONMapper()` gives a baseline mapper without the module
- **Test helpers:** `q("str")` wraps in double-quotes, `a2q("{'a':1}")` converts single to double quotes; assertion helpers `verifyException()`, `assertToken()`
- **SPI test:** Modules registered via SPI include a `ModuleSPIMetadataTest` verifying discovery via `ServiceLoader.load(Module.class)` (currently all except guice, guice7, osgi, and spi-subtypes — the last is registered but has no such test yet)

- **Development branches:** per-minor-version branches (e.g., `2.20`, `2.21`, `2.22`); fixes merge forward (e.g., `2.20` → `2.21` → `2.22` → `2.x`)

- Releases use maven-release-plugin; snapshots deploy to Sonatype Central Portal
